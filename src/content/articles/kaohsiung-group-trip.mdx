## 2 天 1 夜行程

### 👶 親子放電

**Day 1**
抵達 → 駁二與哈瑪星鐵道園區 → 鹽埕午餐 → 壽山動物園 → 入住；若選你好哇寓所，可在 1F 中島廚房準備晚餐，再到公共空間玩桌遊

**Day 2**
鹽埕早餐 → 棧貳庫 → 大港橋散步；如要觀看橋體旋轉，出發前先查高雄港務分公司的當日公告 → 退房返程

**小提示**
帶推車或行動較慢的同行者，仍應先查看景點無障礙資訊、天候與當日人流；館內住宿動線則要注意兩館都沒有電梯。

### 📸 網美打卡

**Day 1**
抵達 → 大港橋拍照 → 駁二大義倉庫群（彩繪牆）→ 新濱・駅前日式老屋咖啡 → 入住你好哇打卡網美吊椅房 → 廢墟 BAR 微醺之夜

**Day 2**
高雄流行音樂中心拍建築 → Kyomo Pasta 午餐 → 棧貳庫白色旋轉木馬 → 退房

**小提示**
下午光線最適合拍照。吊椅房型建議提早預訂。

### 🍜 吃貨攻略

**Day 1**
抵達 → 鴨肉珍（午餐）→ 高雄婆婆冰 → 入住你好哇寓所 → 中島廚房自煮火鍋趴（參考：[高雄有廚房的包棟民宿](/blog/kaohsiung-kitchen-bnb)） → 阿囉哈滷味宵夜 → 鹽埕酒吧

**Day 2**
阿昌虱目魚（早餐）→ 黃家肉燥飯 → 阿綿麻糬（伴手禮）→ 退房返程

**小提示**
建議帶保冷袋，可到全聯採買火鍋料回民宿廚房料理。

## 3 天 2 夜行程

### 🏛️ 文化慢旅

**Day 1**
抵達 → 鹽埕老街散步 → 小堤咖啡 → 入住 → 依官方營運資訊安排愛河夜間行程

**Day 2**
打狗英國領事館（俯瞰西子灣）→ 旗津渡輪 → 旗津老街午餐 → 旗津燈塔咖啡廳 → 回民宿 桌遊同樂 → 空白酒吧

**Day 3**
衛武營藝術中心 → 午餐 → 退房返程

**小提示**
旗津渡輪的班次、票價與可用支付方式請以高雄市輪船公司當日公告為準；假日另預留候船時間。

### ⛴️ 海港風情

**Day 1**
抵達 → 駁二倉庫群 → VR 體驗 → 入住 → 大港橋夜景散步

**Day 2**
渡輪旗津 → 旗津彩虹教堂 + 海水浴場 → 高雄燈塔 → 回程；若入住你好哇寓所，可再安排中島廚房火鍋聚餐

**Day 3**
高雄流行音樂中心 → 棧貳庫午餐 → 退房

**小提示**
夏天旗津海水浴場可玩水，記得帶防曬。

### ☕ 輕鬆休閒

**Day 1**
睡飽 → 大摳胖碳烤三明治（午餐）→ 入住 → 駁二慢慢逛 → 民宿麻將之夜（參考：[高雄有麻將的包棟民宿推薦](/blog/kaohsiung-mahjong-stay)）

**Day 2**
睡到自然醒 → Kyomo Pasta 午餐 → 壽山看夕陽 → 新濱・駅前下午茶 → 廢墟 BAR

**Day 3**
葉家肉粥早餐 → 阿綿麻糬伴手禮 → 退房

**小提示**
不趕行程的旅行最幸福。包棟民宿的好處就是隨時可以回去休息。

## 4 天 3 夜行程

### 🌊 港都全覽

**Day 1**
抵達 → 入住 → 鹽埕老街美食巡禮 → 愛河夜景

**Day 2**
旗津一日遊（渡輪→燈塔→海產→彩虹教堂）→ 西子灣夕陽 → 晚餐

**Day 3**
駁二全日（倉庫群→大港橋→棧貳庫→流行音樂中心）→ 民宿 桌遊之夜

**Day 4**
壽山動物園或瑞豐夜市 → 退房返程

**小提示**
四天三夜最完整！建議第二天租機車遊旗津。

### 🎨 藝文深度

**Day 1**
抵達 → 駁二 VR 體驗館 → 大義倉庫群藝廊 → 入住

**Day 2**
衛武營藝術中心（世界最大單一屋頂劇院）→ 高雄市立美術館 → 內惟藝術中心

**Day 3**
高雄市立圖書館總館（懸吊式綠建築）→ 紅毛港文化園區 → 民宿聚餐

**Day 4**
哈瑪星鐵道園區 → 打狗領事館 → 退房

**小提示**
衛武營可提前買演出票，有不定期國際級表演。

### 🛍️ 購物血拼

**Day 1**
抵達 → 入住 → 新崛江商圈 → 六合夜市

**Day 2**
SKM Park Outlets（全日）→ 義享天地晚餐

**Day 3**
漢神巨蛋百貨 → 瑞豐夜市 → 回民宿打麻將

**Day 4**
鹽埕老街最後巡禮 → 阿綿麻糬伴手禮 → 退房

**小提示**
SKM Park Outlets 有接駁車，建議安排半天以上。

## 住宿建議

所有行程都推薦住鹽埕區[高雄包棟民宿](/kaohsiung-whole-house)（[你好哇寓所](/hellohouse) / [溝頂民宿](/godin)）：
• 步行 10 分鐘到[駁二藝術特區](/blog/pier2-accommodation)
• 步行 5 分鐘到[捷運鹽埕埔站](/traffic)
• [鹽埕美食頁](/explore/food)整理 20 間餐飲，可依分類導航
• [你好哇寓所](/hellohouse)的 1F [中島廚房](/blog/kaohsiung-kitchen-bnb)可正式開伙；[溝頂民宿](/godin)僅有備餐空間
• 兩館均有[手動麻將桌](/blog/kaohsiung-mahjong-stay)，其他設備請以各館頁為準

[你好哇寓所](/hellohouse)開放 8-26 人，[溝頂民宿](/godin)開放 4-12 人；價格請用同一組日期與實際人數在[官網即時查房](/book)查詢。

## 依同行人數選住宿

• 4-12 人：先比較[溝頂民宿](/godin)的 2 間雙人房、2 間四人房與樓梯動線。
• 8-26 人：先看[你好哇寓所](/hellohouse) 6 間房與 1F [中島廚房](/blog/kaohsiung-kitchen-bnb)。
• 27-34 人：可比較[雙館包棟](/compare)（你好哇與溝頂雙館合住）；35-36 人須加床。
• 40 人以上：目前雙館無法單獨承接，需另找合法住宿分流。

兩館都沒有電梯。價格請用同一組日期與人數在[官網即時查房](/book)查詢，再和其他住宿的當期總價比較。
